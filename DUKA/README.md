# Hướng dẫn kết nối Database (dành cho Developer)

1.  Mở file `.sln`.

2.  Bấm Start -> Hiện lỗi chưa kết nối database, chọn "OK".

    <div align="center">
    <img width="511" height="188" alt="image" src="https://github.com/user-attachments/assets/c7afc69a-599c-4f02-896e-2b3fb2adb902">
    </div>

3.  Nhập các thông số: Server, Database, chọn đăng nhập bằng Windows Authentication (bỏ click checkbox nếu muốn dùng username và password).

    <div align="center">
    <img width="437" height="376" alt="image" src="https://github.com/user-attachments/assets/3be4f0e3-932b-4b9d-9edf-7ff6a6cc9fac">
    </div>

4.  Chọn nút "Kiểm tra kết nối" để kiểm tra.

    <div align="center">
    <img width="240" height="194" alt="image" src="https://github.com/user-attachments/assets/f6aecfec-67fa-4eb1-828d-b727d6f723b3">
    </div>

5.  Chọn nút "Lưu" để lưu thông tin kết nối --> lưu thành công sẽ mở form MainMenu.

    <div align="center">
    <img width="222" height="188" alt="image" src="https://github.com/user-attachments/assets/0bfe783c-b3ea-4572-b947-b4985661e317">
    </div>
