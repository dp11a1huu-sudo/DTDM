================================================================================
I. GIỚI THIỆU VỀ GAN
================================================================================

1. Định nghĩa:
   GAN (Generative Adversarial Networks) là một kiến trúc mạng nơ-ron được Ian Goodfellow
   đề xuất năm 2014. GAN bao gồm hai mạng nơ-ron cạnh tranh với nhau:
   - Generator (Máy phát): Tạo ra dữ liệu giả
   - Discriminator (Máy phân biệt): Phân biệt dữ liệu thật và giả

2. Ý nghĩa:
   GAN được lấy cảm hứng từ lý thuyết trò chơi (Game Theory), nơi hai người chơi
   (Generator và Discriminator) cạnh tranh để cải thiện khả năng của nhau.

================================================================================
II. CÁCH HOẠT ĐỘNG CỦA GAN
================================================================================

1. Quy trình huấn luyện:
   a) Generator nhận đầu vào là nhiễu ngẫu nhiên (noise vector)
   b) Generator tạo ra dữ liệu giả (fake data)
   c) Discriminator nhận cả dữ liệu thật và giả
   d) Discriminator phân loại: thật hay giả
   e) Cập nhật tham số dựa trên loss function

2. Loss Function:
   - Discriminator: max log(D(x)) + log(1-D(G(z)))
   - Generator: min log(1-D(G(z))) hoặc max log(D(G(z)))

3. Thuật toán huấn luyện:
   FOR mỗi epoch:
       FOR mỗi batch:
           # Huấn luyện Discriminator
           Lấy batch dữ liệu thật x
           Tạo nhiễu z, sinh dữ liệu giả G(z)
           Tính loss discriminator: L_D = -[log D(x) + log(1-D(G(z)))]
           Cập nhật D

           # Huấn luyện Generator
           Tạo nhiễu z mới
           Tính loss generator: L_G = -log D(G(z))
           Cập nhật G

================================================================================
III. CÁC LOẠI GAN PHỔ BIẾN
================================================================================

1. Vanilla GAN:
   - GAN gốc của Goodfellow
   - Dễ implement nhưng không ổn định

2. DCGAN (Deep Convolutional GAN):
   - Sử dụng Convolutional Neural Networks
   - Ổn định hơn, chất lượng hình ảnh tốt hơn
   - Thay thế pooling bằng strided convolutions

3. WGAN (Wasserstein GAN):
   - Giải quyết vấn đề mode collapse
   - Sử dụng Earth-Mover distance thay vì Jensen-Shannon divergence
   - Gradient penalty thay vì weight clipping

4. CGAN (Conditional GAN):
   - Thêm điều kiện vào input
   - Có thể kiểm soát output (VD: tạo ảnh mèo với màu lông cụ thể)

5. StyleGAN:
   - Tạo ảnh chất lượng cao, có thể điều khiển style
   - Progressive growing: bắt đầu từ ảnh nhỏ, tăng dần độ phân giải

IV. VÍ DỤ THỰC TẾ VỚI PYTHON
================================================================================

1. Import thư viện cần thiết:
```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
import matplotlib.pyplot as plt
```

2. Định nghĩa Generator:
```python
class Generator(nn.Module):
    def __init__(self, latent_dim, img_shape):
        super(Generator, self).__init__()
        self.model = nn.Sequential(
            nn.Linear(latent_dim, 128),
            nn.ReLU(),
            nn.Linear(128, 256),
            nn.ReLU(),
            nn.Linear(256, 512),
            nn.ReLU(),
            nn.Linear(512, img_shape[0]*img_shape[1]*img_shape[2]),
            nn.Tanh()
        )

    def forward(self, z):
        img = self.model(z)
        img = img.view(img.size(0), *img_shape)
        return img
```

3. Định nghĩa Discriminator:
```python
class Discriminator(nn.Module):
    def __init__(self, img_shape):
        super(Discriminator, self).__init__()
        self.model = nn.Sequential(
            nn.Linear(img_shape[0]*img_shape[1]*img_shape[2], 512),
            nn.ReLU(),
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Linear(256, 1),
            nn.Sigmoid()
        )

    def forward(self, img):
        img_flat = img.view(img.size(0), -1)
        validity = self.model(img_flat)
        return validity
```

4. Huấn luyện:
```python
def train_gan(generator, discriminator, dataloader, num_epochs):
    criterion = nn.BCELoss()
    optimizer_G = optim.Adam(generator.parameters(), lr=0.0002)
    optimizer_D = optim.Adam(discriminator.parameters(), lr=0.0002)

    for epoch in range(num_epochs):
        for i, (imgs, _) in enumerate(dataloader):
            # Ground truths
            valid = torch.ones(imgs.size(0), 1)
            fake = torch.zeros(imgs.size(0), 1)

            # Train Generator
            optimizer_G.zero_grad()
            z = torch.randn(imgs.size(0), latent_dim)
            gen_imgs = generator(z)
            g_loss = criterion(discriminator(gen_imgs), valid)
            g_loss.backward()
            optimizer_G.step()

            # Train Discriminator
            optimizer_D.zero_grad()
            real_loss = criterion(discriminator(imgs), valid)
            fake_loss = criterion(discriminator(gen_imgs.detach()), fake)
            d_loss = (real_loss + fake_loss) / 2
            d_loss.backward()
            optimizer_D.step()

        print(f"Epoch {epoch}: G_loss = {g_loss.item():.4f}, D_loss = {d_loss.item():.4f}")
```

================================================================================
V. CÁC VẤN ĐỀ VÀ GIẢI PHÁP
================================================================================

1. Mode Collapse:
   - Vấn đề: Generator chỉ tạo ra một loại output
   - Giải pháp: Sử dụng WGAN, thêm diversity loss

2. Training Instability:
   - Vấn đề: Loss không converge, gradient vanishing
   - Giải pháp: Sử dụng different learning rates, gradient penalty

3. Vanishing Gradients:
   - Vấn đề: Discriminator quá tốt, gradient về 0
   - Giải pháp: Sử dụng Wasserstein loss

4. Evaluation Metrics:
   - Inception Score (IS)
   - Fréchet Inception Distance (FID)
   - Kernel Inception Distance (KID)

================================================================================
IX. CÂU HỎI THƯỜNG GẶP (FAQ)
================================================================================

Q: Tại sao GAN khó huấn luyện?
A: Vì hai mạng cạnh tranh nhau, dễ dẫn đến Nash equilibrium không ổn định.

Q: Làm thế nào để biết GAN đã hội tụ?
A: Khi discriminator không thể phân biệt được thật/giả nữa (accuracy ~50%).

Q: GAN có thể tạo ra dữ liệu vô hạn không?
A: Về lý thuyết có, nhưng chất lượng phụ thuộc vào training data và kiến trúc.

Q: GAN có an toàn không?
A: Có rủi ro về deepfakes và fake news. Cần có watermark và detection methods.

Phụ lục: Code mẫu đầy đủ cho MNIST GAN
================================================================================

```python
import torch
import torch.nn as nn
import torchvision
import torchvision.transforms as transforms
from torch.utils.data import DataLoader

# Hyperparameters
latent_dim = 100
img_shape = (1, 28, 28)
batch_size = 64
lr = 0.0002
epochs = 100

# Data loading
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize([0.5], [0.5])
])

dataset = torchvision.datasets.MNIST(root='./data', train=True,
                                   transform=transform, download=True)
dataloader = DataLoader(dataset, batch_size=batch_size, shuffle=True)

# Generator
class Generator(nn.Module):
    def __init__(self):
        super(Generator, self).__init__()
        self.model = nn.Sequential(
            nn.Linear(latent_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 512),
            nn.ReLU(),
            nn.Linear(512, 1024),
            nn.ReLU(),
            nn.Linear(1024, 28*28),
            nn.Tanh()
        )

    def forward(self, z):
        img = self.model(z)
        img = img.view(img.size(0), 1, 28, 28)
        return img

# Discriminator
class Discriminator(nn.Module):
    def __init__(self):
        super(Discriminator, self).__init__()
        self.model = nn.Sequential(
            nn.Linear(28*28, 512),
            nn.ReLU(),
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Linear(256, 1),
            nn.Sigmoid()
        )

    def forward(self, img):
        img_flat = img.view(img.size(0), -1)
        validity = self.model(img_flat)
        return validity

# Initialize models
generator = Generator()
discriminator = Discriminator()

# Loss and optimizers
criterion = nn.BCELoss()
optimizer_G = torch.optim.Adam(generator.parameters(), lr=lr)
optimizer_D = torch.optim.Adam(discriminator.parameters(), lr=lr)

# Training loop
for epoch in range(epochs):
    for i, (imgs, _) in enumerate(dataloader):
        batch_size = imgs.size(0)

        # Ground truths
        real_labels = torch.ones(batch_size, 1)
        fake_labels = torch.zeros(batch_size, 1)

        # Train Discriminator
        optimizer_D.zero_grad()

        # Real images
        real_loss = criterion(discriminator(imgs), real_labels)

        # Fake images
        z = torch.randn(batch_size, latent_dim)
        fake_imgs = generator(z)
        fake_loss = criterion(discriminator(fake_imgs.detach()), fake_labels)

        d_loss = real_loss + fake_loss
        d_loss.backward()
        optimizer_D.step()

        # Train Generator
        optimizer_G.zero_grad()
        g_loss = criterion(discriminator(fake_imgs), real_labels)
        g_loss.backward()
        optimizer_G.step()

    print(f"Epoch [{epoch+1}/{epochs}] D_loss: {d_loss.item():.4f} G_loss: {g_loss.item():.4f}")

print("Training completed!")
```
